# game-asset-gen

Project adaptation of haxqer/skills game-asset-gen; do not install or run its provider CLI. The reviewed generator walks parent directories for .env, accepts configurable API gateways, uploads references and writes chosen output paths. This project uses the provided image-generation tool without new credential discovery or gateway setup.

Restore the best Git master first. Generate only when the task calls for new art or a specific broken source cannot be restored. Lock identity, silhouette, original palette, outline, canvas, transparent background, direction and attachment contract before generation. Use image edits from the selected seed; make a whole action strip per direction in one edit, not unrelated frame-by-frame pictures. No scenery, captions, badges or ground shadow inside equipment sprites.

Preserve male/female bases and Front/Back/Left/Right. Separate body/head/garment/footwear roles and a common anchor; generation cannot repair a wrong renderer or missing mount metadata. Stage outputs under a NEW work/ candidate directory. Apply sprite-pipeline and tred-asset-quality, inspect native/game scale and all riding/walking directions before changing the atlas index. Never overwrite master PNGs or spend on a batch merely because this skill was selected.
